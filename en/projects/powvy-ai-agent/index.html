Powvy AI Agent

Source code / installation instructions. This project needs installation or setup before use.

A local coding console built on Power: register a project, choose Claude Code or Codex, and run coding tasks with explicit acceptance criteria.

Key features

  • Choose a Claude Code or Codex role for a registered project and specify the task and acceptance criteria
  • Start from the latest Git commit in an isolated working directory; uncommitted local changes are not included automatically
  • Review logs and code diffs and approve operations individually; completed work still needs review and integration
  • Optional Ralph continuous mode with an acceptance command; mobile access must be enabled and paired again on the Mac
