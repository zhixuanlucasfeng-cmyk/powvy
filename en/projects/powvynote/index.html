Powvy Note

Source code / installation instructions. This project needs installation or setup before use.

Hover the top of the screen and a note panel drops out of the Mac notch; on Windows it unfolds from a small pill. Write your timetable once and every week you get blank Monday–Friday class notes, with past weeks kept to look back on.

Key features

  • Weekly timetable: one template, a fresh blank week every week, old weeks under Class or a date search
  • Sidebar search + tag filters: homework / test / class / to-do, with counts
  • macOS (Swift) + Windows (Electron), MIT open source, every note a plain .md file
