Power: a shared room for local AI agents

Power brings local AI agents into one desktop interface. Tools such as Claude Code, Codex, Hermes and opencode still run through their own CLIs; Power provides a shared entry point for chats and projects.

Organizing different tools

Chat with one agent or bring several into a group. Groups support @mentions, automatic selection of a lead, and rounds of discussion. Persona packs define how members speak and their default settings, while project folders give conversations a working context.

Memory you can inspect and edit

Power stores memories as Markdown notes in Obsidian and recalls relevant information in later messages. Those notes can be edited or deleted directly, rather than remaining hidden in an inaccessible state.

What setup involves

Each agent needs its own installation and sign-in. Power organizes the tools; it does not replace their accounts or services. Telegram remote control is optional. Confirmation cards let users review outgoing messages or posts before sending.
