Power：让本机 AI Agents 在同一个房间协作

Power 是一个把本机 AI Agents 放进同一桌面界面的项目。Claude Code、Codex、Hermes 和 opencode 等工具仍通过各自的 CLI 工作，Power 提供统一的聊天与项目入口。

把不同工具组织在一起

可以单独与一个 Agent 对话，也可以把多个 Agent 放进群聊。群聊支持 @ 指定成员、自动选择负责成员，以及按轮次讨论。角色包定义成员的表达方式和默认配置，项目文件夹则为对话提供工作上下文。

记忆可以直接查看和修改

Power 将记忆保存成 Obsidian 中的 Markdown 笔记，并在后续消息中回忆相关内容。记忆不必藏在看不见的状态里：可以直接编辑或删除对应笔记。

使用前需要什么

各个 Agent 需要按自己的方式安装和登录。Power 负责组织这些工具，不代替它们的账号或服务。Telegram 远程控制属于可选配置；发送消息或发布内容前的确认卡片，让用户有机会检查待发送内容。
