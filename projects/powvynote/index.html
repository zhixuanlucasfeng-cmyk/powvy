Powvy Note

此入口提供源码或安装说明，需要安装或配置后使用。

鼠标移到屏幕顶部，便签就从 Mac 刘海里落下来；Windows 版从顶部小黑条展开。写一次自己的课表，每周自动生成空白的周一到周五课表，课堂记录和作业都能留着以后翻。

核心功能

  • 每周课表：写一次模板，每周自动换一份空白的，旧的周点 Class 或搜日期就能找到
  • 侧栏搜索 + 标签筛选：作业 / 考试 / 课 / 待办，带数量
  • macOS（Swift）+ Windows（Electron），MIT 开源，笔记都是普通 .md 文件
