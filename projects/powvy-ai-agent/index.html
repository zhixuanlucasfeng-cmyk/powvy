此入口提供源码或安装说明，需要安装或配置后使用。

基于 Power 的本地编码控制台：登记项目、选择 Claude Code 或 Codex，按任务要求与验收标准推进代码工作。

核心功能

  • 为已登记项目选择 Claude Code 或 Codex 角色，填写任务与验收要求
  • 从 Git 最新提交创建独立工作目录，不自动包含本地未提交修改
  • 查看运行日志与代码差异，逐次批准操作；任务完成后仍需检查和整合
  • 可选 Ralph 持续模式与验收命令；手机远程入口需在 Mac 上重新开启并配对
